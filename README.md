One line of wedding vows for a robot couple, written to get a laugh: the most solemn promise in the book — sickness and health, till death do us part — undercut in the last few words by the most robot failure mode there is. It keeps the wedding cadence (a promise, a commitment, the classic closing line) and the machine side specific: Wi-Fi, airplane mode, a dead battery.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the vow to `out/entry.txt` (124 characters, no trailing newline).
